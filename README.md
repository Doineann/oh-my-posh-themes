
My personal theme(s) for [oh-my-posh](https://ohmyposh.dev/).

There are 4 variants in 2 colors:

| variant          | description                                                                     |
| ---------------- | ------------------------------------------------------------------------------- |
| `blue-leftonly`  | **blue** with powerlines only on the **left** side of the terminal              |
| `red-leftonly`   | **red** with powerlines only on the **left** side of the terminal               |
| `blue-leftright` | **blue** with powerlines on on the **left** and **right** side of the terminal  |
| `blue-leftright` | **red** with powerlines only on the **left** and **right** side of the terminal |
