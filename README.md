
My personal theme(s) for [oh-my-posh](https://ohmyposh.dev/).

There are 2 variants in 3 colors:

| leftonly variant   | description                                                                       |
| ------------------ | --------------------------------------------------------------------------------- |
| `blue-leftonly`    | **blue** with powerlines only on the **left** side of the terminal                |
| `red-leftonly`     | **red** with powerlines only on the **left** side of the terminal                 |
| `green-leftonly`   | **green** with powerlines only on the **left** side of the terminal               |

| leftright variant  | description                                                                       |
| ------------------ | --------------------------------------------------------------------------------- |
| `blue-leftright`   | **blue** with powerlines on on the **left** and **right** side of the terminal    |
| `red-leftright`    | **red** with powerlines only on the **left** and **right** side of the terminal   |
| `green-leftright`  | **green** with powerlines only on the **left** and **right** side of the terminal |
